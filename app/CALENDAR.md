# 交易日历维护

## 当前状态

| 年份 | 状态 | 来源 |
|---|---|---|
| 2025–2026 | 正式 | exchange_calendars XSHG 快照 |
| 2027 | **预排，非官方** | 按农历日期 + 近年放假规律预排 |

2027 年国务院/交易所休市安排截至 2026-10-20 尚未发布，因此：
- 代码中 `2027` 日期只是预排
- 健康状态显示 `2027 预排`
- 不能把预排结果用于真实交易决策

## 官方发布后怎么替换

1. 找到官方公告
   - 国务院办公厅《2027 年部分节假日安排》
   - 上交所《关于 2027 年休市安排的公告》
   - 深交所/北交所同日公告
2. 只保留**工作日休市日**，周末不要写入
3. 修改 `app/src-tauri/src/calendar.rs`
   - 替换 `// 2027 预排（官方安排未发布）` 下的日期
   - 保持 `YYYY-MM-DD` 格式
4. 更新元数据
   - `COVERAGE_END` 按需要延长
   - `is_provisional` 改为只对未发布年份返回 true
   - 文件头注释改为“2027 正式”
5. 跑测试

```bash
cd app/src-tauri
cargo test calendar
```

必须通过：
- 所有日期在工作日
- 无重复
- 日期在覆盖范围内
- 2027 工作日休市数与官方一致
6. 真机验证
   - 健康状态不再显示“2027 预排”
   - 节假日 09:30 显示“休市”
   - 盘前计划日期顺延到下一交易日

## 验收清单

- [ ] 官方公告链接已记录在提交说明
- [ ] 2027 春节/国庆日期与公告一致
- [ ] 周末未写入
- [ ] `cargo test` 全绿
- [ ] 健康提示不再显示“2027 预排”
- [ ] 计划日期在节前最后一个交易日之后正确顺延

## 不要做

- 不要用第三方“预测日历”直接替换正式表
- 不要把周末写入休市表
- 不要在未核对公告的情况下改 `is_provisional`
- 不要只改一处年份而漏掉测试中的 2027 数量断言
